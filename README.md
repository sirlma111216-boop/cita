# 시타델 교실판 (Citadels Classroom)

교사가 클래스를 만들고 학생들이 여러 게임방에서 **실제로 끝까지** 플레이하는 한국어 시타델 웹앱입니다.
Cloudflare Workers + Durable Objects 위에서 동작하며, 게임 판정은 모두 서버가 합니다.

- 배포 주소: https://cita-citadels.sirlma.workers.dev
- 저장소: https://github.com/sirlma111216-boop/cita

## 실행 방법

```bash
npm install
npm run images                 # 원본 PNG → 웹용 WebP (public/img) — 이미 만들어 둔 파일이 저장소에 있음
node scripts/hash-password.mjs '<교사 비밀번호>'   # 출력값이 TEACHER_PASS_HASH
```

로컬 실행용 `.dev.vars` (저장소에 올리지 않음):

```
TEACHER_EMAIL="교사 이메일"
TEACHER_PASS_HASH="pbkdf2-sha256$100000$...$..."
SESSION_SECRET="임의의 긴 문자열"
```

```bash
npm run dev        # http://127.0.0.1:8787 (wrangler dev, 포트가 이미 쓰이면 --port 로 바꾸기)
npm test           # 규칙 엔진·봇 단위 시험 (node --test)
BASE=http://127.0.0.1:8787 EMAIL=... PASSWORD=... node scripts/e2e.mjs   # 실제 서버 전체 흐름 시험
node scripts/demo-students.mjs <클래스코드> 이름1 이름2 ...              # 리허설용 가짜 학생
```

배포:

```bash
npx wrangler secret put TEACHER_EMAIL
npx wrangler secret put TEACHER_PASS_HASH
npx wrangler secret put SESSION_SECRET
npm run deploy
```

교사 비밀번호는 저장소 어디에도 평문으로 두지 않습니다. 서버에는 PBKDF2 해시만 비밀값으로 들어갑니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/engine.js` | 규칙 엔진. 상태 검증·변경, 플레이어별 시야(`viewFor`)만 내려보냄 |
| `src/bots.js` | 연습용 봇. 사람과 같은 시야만 보고 판단 |
| `src/classroom.js` | 클래스 1개 = Durable Object 1개. 명단·게임방·게임 상태, 실시간 연결 |
| `src/registry.js` | 교사의 클래스 목록, 로그인 실패 잠금 |
| `src/auth.js` | PBKDF2 비밀번호 확인, HMAC 서명 토큰, 입력 정리 |
| `public/shared/data.js` | **용어표**: 한국어 명칭 · 영문 원명 · 내부 ID · 비용 · 종류 · 수량 · 효과 |
| `public/shared/assets.js` | **이미지 자산 명세**: 자산 ID · 경로 · 용도 · 비율 · 대체 텍스트 · 연결 ID |
| `public/*.js` | 화면 (시작·교사·학생·대기실·역할 선택·게임·결과·도움말) |
| `assets-src/original/` | 원본 PNG 48장 + SVG 5장 + 생성 프롬프트 (배포하지 않음) |
| `public/img/` | 웹 배포용 WebP (카드 640×960, 배경 1600폭) — 132MB → 4.9MB |

- 4~7인, 기본 역할 8종(암살자·도둑·마술사·왕·주교·상인·건축가·장군)
- 기본 건물 17종 54장(종교 11 · 군사 11 · 귀족 12 · 상업 20 — 규칙서 합계와 일치) + 첫 게임 권장 특수 건물 14장
- 인원별 제외 역할: 4인 공개 2·비공개 1 / 5인 1·1 / 6인 0·1 / 7인 0·1(7번째 사람은 남은 1장과 비공개 제외 카드 중 선택)
- 왕은 공개 제외 불가(나오면 교체 후 다시 섞음)
- 건물 7개 완성 시 그 라운드 끝까지 진행 후 종료. 비용 합계 + 5종류 3점 + 최초 완성 4점 + 다른 완성 2점 + 특수 건물 점수
- 동점: 마지막 라운드에 공개한 역할 번호가 높은 사람
- 버림·파괴 카드는 덱 맨 아래로. 금화 수·손패 장수 공개, 손패 내용 비공개
- 2~3인 규칙, 9번·추가 역할, 구판 8개 건물 종료 조건과 구판 특수 건물 효과는 쓰지 않음

### 자료 확인에 대해

규칙서 PDF의 본문 텍스트(진행·역할 능력 상세·종료·점수·특수 건물 해설)는 직접 추출해 대조했습니다.
인원별 제외 표와 첫 게임 카드 목록은 규칙서 안에서 그림으로 되어 있어 텍스트로 추출되지 않았고,
제외 표는 Order of Gamers 의 2016판 규칙 요약으로 교차 확인했습니다.
**특수 건물의 비용과 카드 문구는 카드 자체에 인쇄된 값이라 규칙서 본문에 없습니다.**
용의 문(6, 추가 2점)·유령 구역·마법 학교 문구는 규칙서 그림에서 확인했고, 나머지 11장의 비용·문구는
2016판 카드 기준으로 입력했습니다. 실제 카드와 다르면 `public/shared/data.js` 한 곳만 고치면 됩니다.

## 의도적으로 바꾼 규칙 (교실용)

1. **첫 왕관 보유자는 무작위** — 원래는 가장 나이 많은 사람. 나이 정보를 모으지 않기 위해서이며 도움말에 표시합니다.
2. **왕은 공개되는 즉시 왕관을 가져감** — 규칙상 차례 중 반드시 가져와야 하므로 자동 처리.
3. **유령 구역의 종류는 앱이 가장 유리하게 자동 선택** — 결과 화면에 어떤 종류로 셌는지 표시.
4. **동점 판정에서 암살당해 공개하지 못한 역할은 가장 낮게 봄** (라운드 끝에 공개되는 암살당한 왕은 4번으로 셈).
5. **자동 턴 타이머 없음**, 연결이 끊겨도 차례를 넘기거나 역할을 공개하지 않음.
6. **연습용 봇** — 원래 규칙에는 없는 교실용 추가 기능. 봇은 자기 손패와 공개 정보만 보고 판단합니다.

## 교실 운영 규칙

- 교사 권한은 서버 인증(PBKDF2 + 서명 토큰)으로만 얻습니다. 화면 조작으로는 얻을 수 없습니다. 로그인 8회 실패 시 10분 잠금.
- 교사가 지정한 학생(방장)만 게임방을 만듭니다. 방장 ≠ 왕관 보유자.
- 학생 한 명은 동시에 한 방에만. 진행 중인 방은 기존 플레이어의 재접속만 허용.
- 방장 연결이 끊겨도 자동 승계하지 않고, 교사가 다시 지정합니다. 진행 중 방장을 해제해도 게임 상태는 그대로입니다.
- 교사는 직접 만든 방에 관리자로 남거나 플레이어로 참가할 수 있습니다. 관리 화면은 공개 정보만 보여 줍니다.
- 학생 표시 이름과 실제 식별자(무작위 ID + 비밀 토큰)는 분리됩니다. 이름이 같아도 자리를 빼앗을 수 없습니다.
- **혼자서 하기(메인 화면)**: 클래스 코드 없이 이름과 봇 수(3~6명)만 골라 바로 한 판. 다른 사람은 들어올 수 없고 교사 목록에도 올라가지 않으며, 24시간 뒤 자동 삭제됩니다. 같은 기기에서는 [하던 혼자 게임 이어하기]로 돌아올 수 있습니다.
- **혼자 연습하기(클래스 안)**: 방장이 아니어도 누구나 봇 3~6명과 바로 한 판. 다른 학생의 방 목록에는 보이지 않고 선생님은 볼 수 있습니다.
- **봇 추가**: 방장·교사는 대기실의 빈자리를 봇으로 채울 수 있습니다.

## 보안·온라인 처리

- 클라이언트는 행동을 요청만 하고, 서버가 권한·차례·비용·대상을 검사합니다.
- 각 연결에는 그 사람에게 허용된 정보만 보냅니다(상대 손패·미공개 역할·비공개 제외 카드·덱 순서는 응답에 아예 없음).
- 모든 요청에 요청 ID(rid)를 붙여 재전송돼도 한 번만 처리하고, 게임 행동은 화면 버전(v)이 맞을 때만 처리합니다.
- Durable Object 가 요청을 하나씩 처리하므로 동시 입장·시작·역할 선택이 정원 초과나 중복 없이 처리됩니다.
- 이름·제목은 서버에서 제어 문자와 꺾쇠를 지우고 길이를 자르며, 화면에는 `textContent` 로만 넣습니다.

## 남아 있는 제한사항

- 특수 건물 11장의 비용·문구는 규칙서 본문이 아닌 2016판 카드 기준 입력값입니다(위 「자료 확인」 참고).
- 교사 계정은 하나(환경 비밀값)입니다. 여러 교사 계정·비밀번호 재설정 기능은 없습니다.
- 학생 신원은 그 기기의 브라우저 저장소에 있습니다. 다른 기기로 옮기면 새 학생으로 참여해야 합니다(교사가 이전 이름을 명단에서 정리 가능).
- 끝난 게임의 결과는 6시간 동안 다시 볼 수 있고, 방을 정리하면 사라집니다. 장기 기록·통계는 없습니다.
- 봇은 단순한 판단 규칙을 쓰는 연습 상대입니다.
- 화면 낭독기 지원은 기본 수준(레이블·역할·라이브 영역)이며, 전문 접근성 감사는 받지 않았습니다.
